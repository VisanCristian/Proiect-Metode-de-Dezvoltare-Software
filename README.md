# Proiect-Metode-de-Dezvoltare-Software

# Pasi de urmat

1. Creeati un environment pentry python
```bash
python3 -m venv .venv
source .venv/bin/activate
# sau pe Windows: .venv\Scripts\activate fara source
```

2. Instalati requirements
```bash
pip install -r requirements.txt
```
3. In `frontend/`
```bash
npm install
```
4. In `backend/`
```bash
python3 manage.py migrate
```
